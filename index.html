PROJETO 01TCC · em desenvolvimento

Assistente virtual para gestão de despensa

Python · Telegram · Gemini API · SQLite · JSON

Desenvolvi um assistente para organizar uma despensa doméstica por meio de conversas e diferentes interfaces. O bot do Telegram usa o Google Gemini para interpretar mensagens em linguagem natural e extrair produtos de fotos de notas fiscais.

As operações são convertidas em dados estruturados e executadas pelas regras do sistema, com persistência em SQLite (Protótipo) e separação dos estoques por usuário. O projeto também inclui uma interface web com FastAPI para consultar e atualizar itens, uma API para integração com Atalhos do iOS e lembretes periódicos de estoque. A arquitetura separa as interfaces das regras de negócio, permitindo que Telegram, site e Atalho compartilhem as mesmas operações da despensa.

Tecnologias: Python, Google Gemini, Telegram Bot API, FastAPI, SQLite, APIs HTTP/JSON.

Avaliação piloto: 39 mensagens em sete categorias, repetidas três vezes. Acerto geral de 88,9% para 99,1% após correções; resultado preliminar, pois as mesmas perguntas orientaram os ajustes e nova rodada, teste de fotos e usabilidade seguem pendentes.
